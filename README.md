# Custify - Système de Gestion de Relation Client (CRM)

## 📋 Objectif du projet

Custify est une application web de gestion de relation client (CRM) conçue pour permettre aux entreprises de gérer efficacement leurs interactions avec les clients, les prospects et les opportunités commerciales. L'application offre une solution complète pour centraliser et organiser toutes les informations relatives aux clients, faciliter la collaboration entre les équipes commerciales et administratives, et optimiser le suivi des opportunités de vente.

## ✨ Fonctionnalités principales

### 1. **Authentification et Gestion des Utilisateurs**
   - Authentification sécurisée (login/logout)
   - Gestion des rôles et permissions
   - Gestion des profils utilisateurs
   - Modification des rôles utilisateurs (administrateur)
   ect

### 2. **Gestion des Clients**
   - Création et modification des fiches clients
   - Visualisation de la liste complète des clients
   - Consultation des détails des clients
   - Association des clients aux canaux de communication

### 3. **Gestion des Prospects**
   - Suivi des prospects potentiels
   - Conversion des prospects en clients
   - Historique des interactions avec les prospects

### 4. **Gestion des Interactions**
   - Enregistrement des interactions avec les clients
   - Suivi des communications (appels, emails, réunions, etc.)
   - Historique des interactions par client

### 5. **Gestion des Opportunités**
   - Création et suivi des opportunités de vente
   - Gestion du pipeline commercial
   - Suivi des étapes des opportunités

### 6. **Gestion des Canaux de Communication**
   - Configuration des canaux (email, téléphone, chat, etc.)
   - Association des participants aux canaux
   - Gestion des messages par canal

### 7. **Tableau de Bord**
   - Vue d'ensemble des activités
   - Statistiques et métriques clés
   - Indicateurs de performance commerciale

### 8. **Gestion des Accès et Sécurité**
   - Contrôle d'accès basé sur les rôles (RBAC)
   - Gestion des permissions granulaires
   - Pages d'accès refusé

## 🛠 Stack Technologique

- **Framework** : Spring Boot 4.0.5
- **Langage** : Java 17
- **Base de données** : (À spécifier - MySQL, PostgreSQL, etc.)
- **Build Tool** : Maven
- **Frontend** : HTML, CSS, Thymeleaf
- **Sécurité** : Spring Security
- **ORM** : Spring Data JPA

## Installation et Démarrage

### Prérequis
- Java 17 ou supérieur
- Maven 3.6 ou supérieur
- Base de données (MySQL/PostgreSQL)

### Étapes d'installation

```bash


# Construire l'application
./mvnw clean build

# Démarrer l'application
./mvnw spring-boot:run
```

L'application sera accessible à : `http://localhost:8080`
